## Student Record Management System

I developed a simple console-based Student Record Management System.

### Features

* Add Student
* View All Students
* Search Student by Roll Number
* Update Student Information
* Delete Student
* Display Total Number of Students
* Menu-driven interface
* Calculate average marks
* Assign grades

## Grading Criteria

| Average Marks | Grade |
