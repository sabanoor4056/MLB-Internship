# Day 13 - Iris Flower Classification
## Project Overview
This project uses Machine Learning to predict the
species of an Iris flower from its measurements.
## What is Classification?
Classification is a Machine Learning technique that
predicts categories or class labels.
Example: Predicting whether a flower is Setosa,
Versicolor, or Virginica.
## Classification vs Regression
- Classification predicts categories.
- Regression predicts numerical values.
## Dataset
I used the built-in Iris dataset from Scikit-learn.
It contains:
- 150 flower samples
- 4 input features
- 3 flower species
## Algorithm
Logistic Regression
Bonus: Decision Tree Classifier
## Data Preparation
- Loaded the Iris dataset.
- Split the data into 80% training and 20% testing.
- Standardized features for Logistic Regression.
## Evaluation Metrics
- Accuracy: Overall correct predictions.
- Precision: Reliability of positive predictions.
- Recall: Ability to identify actual positive cases.
- F1-Score: Balance between precision and recall.
- Confusion Matrix: Correct and incorrect predictions
  for each flower species.
