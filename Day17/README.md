# Day 17 – Fashion MNIST Image Classifier using CNN
## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify clothing images from the Fashion MNIST dataset using TensorFlow and Keras.
## Tasks Completed
- Loaded and explored the Fashion MNIST dataset.
- Visualized 10 sample images with labels.
- Normalized image pixel values.
- Built and trained a CNN model.
- Evaluated training and testing accuracy and loss.
- Generated accuracy and loss graphs.
- Created a confusion matrix.
- Displayed 10 correct and 10 incorrect predictions.
## Model Architecture
- Convolution Layer: Extracts image features.
- Max Pooling Layer: Reduces feature-map size.
- Flatten Layer: Converts features into a one-dimensional array.
- Dense Layer: Learns patterns for classification.
- Output Layer: Predicts one of 10 clothing classes.
## Why CNNs?
CNNs are suitable for image data because they learn spatial features such as edges, shapes, and patterns. Pooling reduces feature-map size and computation.
