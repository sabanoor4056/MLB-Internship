# Day 3 - Python Conditions, Loops & Logic Building

## Number Analysis Tool

A beginner-friendly Python program that analyzes a number and displays whether it is even or odd, prime, the number of digits, its reverse, and whether it is a palindrome.

## Concepts Learned

* Conditional statements (`if`, `elif`, `else`)
* Logical operators (`and`, `or`, `not`)
* `for` loops
* `while` loops
* `break` statement
* Nested loops
* Modulus operator (`%`)
* Integer division (`//`)
* Input and output
* Basic problem-solving and logic building

## Mini Challenge

Created a **Number Analysis Tool** that:

* Accepts a number from the user
* Checks whether it is even or odd
* Checks whether it is prime
* Counts the number of digits
* Reverses the number
* Checks whether it is a palindrome
* Displays all results in a user-friendly format

## Challenges Faced

* Understanding the difference between `for` and `while` loops
* Understanding the modulus (`%`) operator
* Building logic for reversing a number
* Understanding how to check prime numbers
* Combining multiple concepts into one program

## Lessons Learned

I learned how to use conditions and loops to solve programming problems. I also improved my understanding of logical thinking, number operations, and breaking a problem into smaller steps before writing code.
