
# Day 25 - Image Transformations and Enhancement

## 1. Objective
To learn image transformations and image enhancement
using Python and OpenCV.

## 2. Coding Practice
Implemented the following techniques:

- Image Translation
- Image Rotation
- Image Scaling
- Affine Transformation
- Perspective Transformation
- Brightness Adjustment
- Contrast Adjustment
- Gaussian Blur
- Median Blur
- Bilateral Filter
- Image Sharpening

## 3. Mini Project
Document Image Enhancement Tool

The application improves document image quality by:

- Correcting document perspective
- Converting images to grayscale
- Removing noise
- Improving brightness and contrast
- Sharpening document text
- Saving enhanced images

## 4. Dataset
Used 10 document images for testing.

## 5. Challenge Task
Processed 5 tilted document images.

Compared:
- Original Images
- Perspective Corrected Images
- Final Enhanced Images

## 6. Biggest Impact
Perspective transformation had the biggest impact
on tilted documents because it straightened the page.
Contrast enhancement also improved text visibility.

## 7. Challenges
- Finding document corners
- Adjusting transformation coordinates
- Selecting suitable filter parameters
- Maintaining clear text after enhancement

## 8. Conclusion
Learned how to perform image transformations and
enhancement using OpenCV.

These techniques are useful for document scanning,
OCR and computer vision applications.
