# Day-6 — NumPy, Pandas & Student Performance Analysis

## Overview

Today I learned the basics of NumPy and Pandas and applied them to a Student Performance Analysis project.

## NumPy

I learned how to:

* Create 1D and 2D arrays.
* Perform arithmetic operations.
* Find maximum, minimum, mean, and sum.
* Reshape arrays.
* Use indexing and slicing.

## Pandas

I learned how to:

* Create Series and DataFrames.
* Load CSV datasets.
* Explore datasets using `head()`, `tail()`, and `info()`.
* Find missing values.
* Filter data.
* Calculate summary statistics.

## Student Performance Analysis

I analyzed a student dataset containing Math, English, and Computer marks.

### Key Insights

* Calculated average marks for each subject.
* Calculated the overall average of each student.
* Identified the top 5 performing students.
* Identified students scoring below the class average.
* Found the total number of students.
* Saved the analyzed data as a new CSV file.

## Challenges

The main challenges were understanding DataFrame operations, calculating averages, filtering students, and ensuring that all dataset columns had the same number of values.

## Outcome

I gained basic practical experience with NumPy arrays, Pandas DataFrames, CSV files, filtering, statistics, and basic data analysis for Machine Learning preparation.
